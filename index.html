Unlock your homelab from your phone

Your server boots with its encrypted drives locked. Open the app, use your fingerprint, and the drives unlock, the pool comes back and your containers start. The passphrases never leave your phone unencrypted.

How it works

A small Rust service waits at boot. Your phone talks only to the server it was paired with.

BootThe server starts with LUKS drives locked and publishes an unlock request.
Open the appIt verifies the server's pinned identity and shows which drives are waiting.
FingerprintA biometric releases the passphrases, sealed to a one-time key held only in server memory.
Back to normalDrives unlock and mount, the mergerfs pool refreshes, your scripts bring up the containers.

Built to be boring and safe

LAN only, no cloud, no relay, no account.

🔐

End-to-end encrypted

HPKE to a per-request ephemeral key on top of pinned TLS 1.3. Recorded traffic or a stolen disk reveals nothing.

🤳

Biometric vault

Passphrases sit in an Android Keystore vault that needs a fresh strong biometric for every use.

🛡️

No impersonation

Pairing is done once over a QR from your SSH console. A changed server key is a hard failure.

⚙️

Post-unlock scripts

Run scripts automatically after unlock, or start them from the app. Only containers that need the drives wait.

🧩

OpenMediaVault aware

Mounts through your existing fstab entries and refreshes the mergerfs pool like the OMV plugin does.

🪶

Tiny and sandboxed

A small native systemd service, locked down to a low exposure score. Revoke a lost phone with one command.

Install on the server

Signed apt repository for Debian 13 / OpenMediaVault 8, amd64. Current version: 0.3.0.

1. Add the repository and install 
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://mblcdr.github.io/server-hands/server-hands.gpg | sudo tee /etc/apt/keyrings/server-hands.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/server-hands.gpg] https://mblcdr.github.io/server-hands/ ./" | sudo tee /etc/apt/sources.list.d/server-hands.list
sudo apt update && sudo apt install server-hands

The service is not enabled automatically. Continue with the setup guide: discover drives, pair your phone, add post-unlock scripts.

2. Verify the signing key

Compare this fingerprint with the one in the project README before trusting the key:

8A6B7750C817E5BFCEAE8B34023D040E2ACC8026
gpg --show-keys --with-fingerprint /etc/apt/keyrings/server-hands.gpg
